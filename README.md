# MPAcc 199 数学全考点公式宝典

面向管理类联考（MPAcc / MBA / MPA / MEM 等 199 管综）考生的全考点数学公式百科、高频速记清单与互动推演复习系统。所有数学公式基于 KaTeX 高清排版渲染，支持本地学习进度记忆与离线打包导出。

## 核心功能模块

1. **公式百科全考点**
   - 完整覆盖管理类联考数学 7 大知识模块（算术与数论、代数与方程、函数与数列、平面与立体几何、平面解析几何、排列组合与概率统计、应用题与条件充分性判断）。
   - 每条考点均包含：核心公式与推导变形、速记口诀、适用条件、易错陷阱警示、一键复制 LaTeX 源码，以及一道经典联考真题的分步解析。
   - 支持关键词实时搜索、按考频/收藏/未掌握状态筛选，以及本地学习进度追踪（基于 `localStorage`）。

2. **高频速记清单与真题实战**
   - 精选历年联考高频必考公式类别，采用“左侧极简公式 + 口诀 / 右侧真题三步拆解”的对照排版，适合考前冲刺快速过遍，并支持 A4 打印或另存为 PDF。

3. **互动公式推演实验室**
   - **二次函数与韦达定理实验室**：实时调节 $a, b, c$ 参数，观察抛物线图像、对称轴、判别式 $\Delta$ 与实根分布变化。
   - **绝对值“平底锅”最值推演器**：拖动零点与试探点，直观理解数轴折线与中位数取最值的几何本质。
   - **直线与圆弦长位置沙盒**：动态计算圆心距 $d$、半径 $R$、相交/相切/相离判定及弦长 $L = 2\sqrt{R^2-d^2}$。
   - **多次稀释浓度推演器**：可视化演示反复倒出加满水模型的等比浓度衰减过程。

4. **易错与条件充分性判断专题**
   - 梳理条件充分性判断（A–E 选项）逻辑判定矩阵、考场十大高频易错陷阱及必备平方/立方/质数/勾股/错位排列速查表。

5. **抽背自测卡片**
   - 支持按模块或“仅未掌握考点”进行主动回忆抽背，一键打乱卡组顺序并实时更新掌握状态。

6. **一键打包下载**
   - 支持在浏览器端直接打包下载**全套公式 Markdown/LaTeX 笔记资料包（`.zip`）**及**完整应用源代码（`.zip`）**。

## 技术栈

- **框架**：React 19 + TypeScript + Vite
- **样式**：Tailwind CSS v4
- **公式排版**：KaTeX
- **图标与打包**：Lucide React + JSZip

## 本地运行与构建

确保本地已安装 Node.js（建议 v18+），在项目根目录执行：

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务器（默认端口 3000）
npm run dev

# 3. 类型检查
npm run lint

# 4. 构建生产环境静态产物
npm run build
```
